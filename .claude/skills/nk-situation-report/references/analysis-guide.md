# 분석 가이드 (KINAC 카테고리 축)

## 입력
- `sources/YYYY-MM-DD/index.json` — 전체 분류·태깅 현황
- `sources/YYYY-MM-DD/items/src-XXX.json` — `new`/`update` 항목만 개별 열람
- `reports/YYYY/MM/*.md` — 이전 7일 보고서

## 분석 과정

### 1. KINAC 카테고리별 정리 (1차 축)
`kinac_relevant: true` 기사를 4대 카테고리로 묶어 정리한다:
- **지역**(평산/강선/영변/풍계리) 동향
- **핵물질 생산**(우라늄/플루토늄) 동향
- **핵주기**(광산~재처리 공정) 동향
- **핵주기시설**(농축시설/원자로/방사화학실험시설) 동향

각 기사에 대해:
- **중요도:** 높음(핵물질·핵주기·시설 직접 진전) / 중간(전문가 평가·분석) / 낮음(배경)
- **이전 보고서 연관:** 직접 연관 없음 / 맥락적 연결 있음

### 2. 기존 보도 추적 (tag: update)
- **원본:** 어떤 날짜의 어떤 항목과 연결되는지
- **변경/추가 정보:** 구체적으로 무엇이 새로운지
- **추적 가치:** 높음 / 낮음

### 3. 제외 기사 (tag: reported)
- **제외 근거:** 원본 참조 + 새 정보 없음 확인

### 4. 배경 동향 (kinac_relevant: false)
4대 카테고리 미해당이나 키워드는 통과한 기사 — 간략히 별도 정리(외교·제재 등 일반 동향).

## 산출물 1: analysis.md
```markdown
# 연관관계 분석 (YYYY-MM-DD)

## 분석 요약
- 핵활동 직접 관련: N건 / 배경 동향: N건 / 신규: N · 업데이트: N · 제외: N

## 카테고리별 분석
### 지역
#### [src-001] 제목
- **중요도:** 높음  **카테고리:** 지역(영변), 핵주기시설(원자로)
- **분석:** 왜 중요한지 1-2문장

### 핵물질 생산
...
### 핵주기
...
### 핵주기시설
...

## 기존 보도 추적
### [src-010] 제목
- **원본:** YYYY-MM-DD 보고서 "항목 제목"
- **변경사항:** 구체적 새 정보  **추적 가치:** 높음

## 배경 동향 (카테고리 미해당)
- 간략 정리

## 제외 기사
### [src-015] 제목 — 제외 근거
```

## 산출물 2: report-basis.md

```markdown
# 보고서 작성 근거 (YYYY-MM-DD)

## 포함 항목
| 순서 | 소스 ID | 제목 | 카테고리 | 태그 | 포함 근거 |
|------|---------|------|----------|------|----------|

## 제외 항목
| 소스 ID | 제목 | 제외 근거 |

## 보고서 구성 방향
- 카테고리별 강조점 / 추적 항목 / 배경 동향 처리
```
