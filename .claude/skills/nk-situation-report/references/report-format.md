## 포함 기준
- `report-basis.md`에서 "포함"으로 결정된 항목만.
- 본문은 KINAC 4대 카테고리 섹션 구조를 **항상 유지**한다(해당 기사 없는 카테고리는 "해당 없음" 표기).
- `tag: new` → 신규 / `tag: update` → 업데이트(이전 보고서 참조) / `tag: reported` → 본문 제외.
- 출처 URL 없는 정보는 포함하지 않는다.
- 한 기사가 복수 카테고리에 해당하면 가장 핵심적인 카테고리 1곳에 본문을 두고, 다른 카테고리 섹션에는 "→ N번 항목 참조"로 교차 표기.
- 동일 뉴스 여러 매체 보도 시 대표 1개를 본문에, 나머지는 출처 목록에.

## 특이사항 없음 처리
포함 항목 0건이면 동일 구조(4대 카테고리 섹션 모두 "해당 없음")로 "특이사항 없음" 보고서를 생성한다. 보고서 파일은 항상 생성한다.
